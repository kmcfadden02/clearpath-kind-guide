# Clearpath Kind Guide

Clearpath is an AI-powered mobile application designed to help older adults confidently navigate the digital world. The app serves as a personal digital safety companion, protecting users from scams, guiding them through technology, and providing easy access to trusted support when needed.

As technology becomes increasingly important for daily life, many seniors face challenges such as identifying online scams, using unfamiliar apps, managing digital accounts, and understanding emerging technologies. Clearpath addresses these challenges through a simple, accessible, and user-friendly platform specifically designed for older adults.

We plan to improve this design by allowing multiple questions to be asked about the same problme. Currently our project only allows for the initial question to be asked. We also plan to get our own domain for the website instead of using lovable for the backend. Our website is currently editable by anyone that can access the link and log into lovable which is not ideal. Since the app will be dealing with sensitive information we will need to use our own AI and have a security mechanism that prevents against data leakage and more API tokens for the users to have.

Our goal is to make this app widely available, so we don't want to make a subscription based app, but since there is use of AI there will be a need for money to pay for those services so our thoughts are to run ads, and if that isn't enough to add a very small subscription to match needs.
